Phase 2: Downloading Your Library

1. Set Your Music Folder
    The script will ask you to enter a folder name (defaulting to "Music Library") and provide numbered suggestions for where to save it (like your Music or Downloads folder). Type the number of your preferred location and hit Enter. The script will automatically create the folder and direct all downloads there.

2. Search for a Track
    In the script's main menu, type `1` and press Enter. 
    Instead of dealing with URLs, the script will ask you to Enter the 'Artist - Song Title'. Type the artist and song name you want (e.g., "Kendrick Lamar - squabble up") and press Enter.

3. Automated Magic
    The script will now completely take over. It will:
    - Silently query the iTunes API to grab the exact Artist, Title, Album, Genre, Year, Track/Disc numbers, Explicit tags, and 1000x1000 cover art.
    - Search YouTube for the best audio source and download it.
    - Force FFmpeg to convert the stream to a strict 320kbps MP3.
    - Embed all the metadata directly into the file.

4. Smart Resume
    Pro-Tip for large batches: If you search for a song you've already downloaded, the script detects the existing file in your folder. It will instantly skip the download phase and strictly update the ID3 metadata tags, saving you time and bandwidth.
