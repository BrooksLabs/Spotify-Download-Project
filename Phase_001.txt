Phase 1: Setting up the Tools

1. Install Python (The Foundation)
    Windows: Go to Python.org and download the latest installer[cite: 8]. Crucial step: When you run the installer, look at the very bottom of the first window and check the box that says "Add Python to PATH" before clicking install[cite: 8]. If you miss this, nothing else will work[cite: 8].
    Mac: Modern Macs usually have Python pre-installed[cite: 8]. If not, download the macOS installer from Python.org[cite: 8].

2. Open your Terminal / Command Prompt
    Windows: Click the Start button, type cmd, and hit Enter[cite: 8].
    Mac: Press Cmd + Space, type Terminal, and hit Enter[cite: 8].

3. Run the Downloader Script
    Navigate to the folder where you saved the python file. Type `python youtube_audio_downloader.py` (or `python3 youtube_audio_downloader.py` on Mac) into the terminal and press Enter.

4. Automated Dependency Setup
    You no longer need to manually type pip commands. The script will automatically check for and install `yt-dlp` and `mutagen` the moment it launches.

5. Install FFmpeg
    The script will prompt you to check or install FFmpeg, which is required to encode the final 320kbps MP3s. Simply type `Y` and press Enter to let the script automatically configure it via winget (Windows) or provide exact instructions for your OS (Mac/Linux).
